
# Student Attendance System

## Project Description

The Student Attendance System is a simple website designed to help manage student attendance. It allows users to view student records, mark attendance, and organize attendance information by date.

## Features

- View the student attendance list
- Add new students
- Remove students
- Search students by ID or name
- Mark students as Present, Absent, or Late
- View attendance summaries
- Select an attendance date
- Reset attendance records for a selected date
- Export attendance records to CSV
- Save information in the browser

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
- GitHub Pages

## How to Use

1. Open the website in a browser.
2. View the student attendance dashboard.
3. Add a student using the form.
4. Select a date.
5. Change each student's attendance status.
6. Search for a student using the search bar.
7. Export the attendance list as a CSV file when needed.

## Storage Information

The website uses browser Local Storage to save student information and attendance records. Data is stored on the current browser and device. It is not connected to a central database.
